# 中文文章格式化（cn-doc-format）

对中文 Markdown / R Markdown 文稿执行机械、安全的编排规范化。规范依据是
style-guide/docs 下的六个文件（标题 title.md、文本 text.md、段落
paragraph.md、数值 number.md、标点符号 marks.md、文档体系 structure.md）。

## 使用方式

脚本无需任何第三方依赖，Python 3.8+ 直接运行：

```bash
ZF=/Users/flora/.agents/skills/cn-doc-format/scripts/zhformat.py

python3 $ZF --diff 文件.md          # 预览差异（建议总是先 diff 再写入）
python3 $ZF -i 文件或目录...         # 原地修改；目录会递归处理 .md/.Rmd/.markdown/.txt
python3 $ZF --check 目录            # 只检查不改写，有需要格式化的文件时退出码为 1
python3 $ZF --lint 目录             # 只输出结构警告（标题层级跳跃等）
python3 $ZF 文件.md                 # 格式化结果输出到 stdout
```

选项：

- `--no-digit-space`：中文与数字之间不加空格（规范允许"加或不加"，但必须全文统一；默认加）
- `--no-thousands`：不为五位以上数字添加千分号

## 自动修正的规则

| 规则 | 内容 | 出处 |
|------|------|------|
| T1 | 全角中文与半角英文/数字之间加一个半角空格 | text.md (1)(2)(3) |
| T2 | 半角字符与全角标点之间不留空格 | text.md (4) |
| M1 | 中文相邻的半角 `, ; : ! ? ( ) .` 转全角（`8:00`、`1,000`、`3.14` 不受影响） | marks.md 原则(1) |
| M2 | 中文语境直引号 `"` `'` 转弯引号并按序配对（英文撇号 man's 不动） | marks.md 引号 |
| M3 | `...`、`。。。`、单个 `…` → `……` | marks.md 省略号 |
| M4 | 感叹号连用 `!!`／`！！` → 单个 | marks.md 感叹号(2) |
| M5 | 中文之间的 `--` → `——`；三个以上 `—` → `——` | marks.md 破折号 |
| M6 | 年份式数值区间 `2009-2011` → `2009～2011`（不动 `2001-12-25` 日期） | marks.md 连接号(3) |
| M7 | 全角标点（开/闭引号、括号、点号）与中文之间的空格删除，内外两侧都删（`曾 ‘文字’ ，` → `曾‘文字’，`；`——` 前后的空格是规范允许的形式，不动） | marks.md 括号(1)、text.md (4) |
| M8 | 标有书名号/引号的并列成分之间的顿号删除（`《A》、《B》` → `《A》《B》`，GB/T 15834） | marks.md 顿号 |
| N1 | 全角数字 `０-９`、全角百分号 `％` → 半角 | number.md |
| N2 | 五位以上整数加千分号 `50000` → `50,000`（四位数不动） | number.md |
| P1 | 段首不留空白（含全角空格 `　`） | paragraph.md |
| P2 | 多个连续空行收敛为一个 | paragraph.md |
| H1 | 标题末尾的点号（。，、；：）删除（？！等标号保留） | marks.md 原则(4) |

只警告、不自动修改的规范（`--lint` 输出）：标题层级跳跃（如 H1 直接到 H3）。
句子长度、被动语态、"的地得"等语言层面的规范无法机械判断，不在本工具范围内，
需要人工或模型审读。

## 保护机制（不会被改动）

- 文件开头的 YAML frontmatter（`---` 之间）
- 代码围栏 ` ``` ` 内的内容
- 行内代码 `` `...` ``、URL、Markdown 链接目标 `[文字](url)`、邮箱
- Pandoc 属性 `{.hline ...}` `{.c ...}` 等
- 不含中文字符的整行英文（整句英文用半角标点，符合 marks.md 原则(2)）

## 已知边界

- 英文并列词之间的半角逗号（`Google, Facebook`）不会自动改顿号——规范虽建议
  用顿号，但"并列"与"一般停顿"无法可靠区分，需人工处理。
- 弯引号配对按行内出现顺序开闭交替；原文引号不配平时结果可能错误，批量执行前
  先用 `--diff` 抽查。
- 格式化会改写文件内容；对版本库中的文件先确认 git 工作区干净，便于审阅 diff。

## 典型工作流

```bash
# 1. 抽查几个文件的差异
python3 $ZF --diff chat/2001-01-*.Rmd

# 2. 确认无误后批量原地格式化
python3 $ZF -i chat/

# 3. 结构检查
python3 $ZF --lint chat/
```
